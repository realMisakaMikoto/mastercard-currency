## 修复

**离线时报错指向了错误的原因。**

v1.5.0 及更早版本里，只要换算页没拿到，就一律提示：

> 万事达拒绝对本机浏览器会话返回换算页（Akamai Access Denied）。
> 该拦截基于客户端指纹而非网络……

但「页面根本没到达」和「边缘明确拒绝」是两回事。飞行模式下页面加载失败（
`net::ERR_INTERNET_DISCONNECTED`）也会走到同一分支，于是断网的用户被告知「你的浏览器指纹被识别了」，
会去排查一个根本不存在的问题。

现在区分三种失败：

| 失败类型 | 判定依据 | 提示 |
|---|---|---|
| 页面未到达 | WebView 网络错误 / 加载超时 | 网络无法访问官网（离线、DNS 或连接被阻断），请检查网络 |
| 边缘拒绝 | HTTP 403 / Akamai Access Denied 文档 | 拒绝返回换算页，该拦截基于客户端指纹而非网络 |
| 其它 HTTP 错误 | 具体状态码 | 对应的状态说明 |

实测（飞行模式 + 点查询）：

```
未能获取汇率
没有取到万事达的换算页，通常是当前网络无法访问 www.mastercard.com
（离线、DNS 或连接被阻断）。请检查网络后重试；若已联网仍失败，
可点「查看诊断」确认，或改用「手动输入汇率」。
```

## 工程

- 新增 `PageFailureClassificationTest`：确保三个失败标记互不为子串（否则分类会退化），
  且离线提示不会出现「指纹」「Akamai」等误导词。
- 测试数 67 → **71**。
