# v1.5.0

## ⚠️ 自用版本 / Personal use only

个人自用构建，非官方产品：无官方支持、无可用性保证。
Mastercard / 万事达名称与双圆标识为其商标，本项目仅限个人学习与自用，详见 [NOTICE.md](../NOTICE.md)。

## 修复

- **WebView 并发**：预热与查询会串行执行，不再可能同时操作同一个 WebView。
  新增回调 generation，超时后延迟返回的 JS 回调不会污染下一次请求。
- **重复查询**：查询进行中会禁用查询与互换按钮，并在 ViewModel 层直接拒绝第二次请求。
- **历史日期**：显式选择的历史日期**不再回退到当前最新汇率**。
  过去查不到时只在**向过去最多 7 天**内寻找最近可用汇率（覆盖周末与连续假期）；
  7 天都没有数据会明确报错，而不是悄悄给出今天的汇率。
- **金额精度**：按目标货币的 ISO 4217 小数位换算与显示 —— JPY/KRW 0 位、KWD/BHD/JOD/OMR/TND 3 位、
  其余 2 位。此前固定两位，会把 JPY 显示成 `123.00`。
- **金额一致性**：金额未被改动时直接采用万事达返回的 `crdhldBillAmt`；改动后才做本地即时换算。
- **移除无用兜底**：正式查询不再尝试 legacy settlement 路径与原生 HTTP 兜底
  （两者都必然 403，只会让用户多等超时）。原生 HTTP 保留为开发者面板里的探测。
- **WebView 收紧**：主框架只允许停留在万事达域名下，离开即拒绝并作废当前会话；
  子资源（CDN / Akamai / Cookie 同意）不受影响。
- **诊断标记**：网络异常时的 fetch layer 标记不再一律写成 WebView。
- **Manifest**：`allowBackup=false`（无值得备份的数据，且 WebView 会保留会话 Cookie）。

## 工程

- 新增 GitHub Actions：单元测试 + debug 构建（必过），lint 非阻塞，产物上传 debug APK。
  CI 不接触任何 release 签名材料。
- 测试从 35 项扩到 **66 项**：新增日期回退、货币小数位、并发门禁三组，
  并校验随包数据集确实符合 ISO 4217。
- release 签名不再有默认口令；密钥缺失时产出未签名 APK。
- 更新隐私与数据来源声明。

## 仍然存在的限制

- 依赖万事达官网页面结构与 Akamai 会话，官网改版后可能需要适配。
- 本项目不是万事达官方客户端，未使用任何商户凭证。
- 实际入账金额最终以发卡行为准。
